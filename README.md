Basic Chatbot using Python

About the Project

This is a simple rule-based chatbot developed using Python. It interacts with users through text input and provides predefined responses.

Features

- Greets users.
- Responds to "Hello".
- Answers "How are you?"
- Exits when the user types "bye".
- Handles unknown messages.

Technologies Used

- Python
- While Loop
- If-Else Conditions
- User Input and Output

How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the terminal.
4. Run:

python CodeAlpha_chatbot.py
